# ตี้ป่วน (Teepuan Games)

เกมสั้นแก้เบื่อสำหรับคอมมูนิตี้ตี้ป่วนบน LINE OA / OpenChat เล่นจบใน 30–90 วินาที บนมือถือ

- หน้ารวมเกม: https://songyisong88.github.io/teepuan-games/
- **หอคอยเหล็ก (STEEL STACK)**: https://songyisong88.github.io/teepuan-games/steel-stack/
  แตะให้ถูกจังหวะ วางบล็อกเหล็กซ้อนให้สูงที่สุด วางตรงเป๊ะได้คอมโบ
- **งูมือถือยุค 90 (SNAKE '98)**: https://songyisong88.github.io/teepuan-games/snake/
  มือถือปุ่มกดจอเขียว บังคับงูกินจุด มี 3 โหมด: คลาสสิก / ไม่มีกำแพง / เขาวงกต
- **พินบอลยุค 90 (DEEP CORE PINBALL)**: https://songyisong88.github.io/teepuan-games/pinball/
  พินบอลโต๊ะเอียงสไตล์โปรแกรมคอมยุค 90 แตะครึ่งซ้าย/ขวาของจอเพื่อตีไม้ กดค้างแล้วปล่อยเพื่อยิงลูก
- **กบข้ามถนน (KLONG HOP '94)**: https://songyisong88.github.io/teepuan-games/frog/
  ตู้เกมยุค 90 พากบหลบรถ ขี่ขอนไม้และแพไม้ไผ่ข้ามคลอง เข้ารังให้ครบ 5 ช่อง ปัดจอหรือกดปุ่มลูกศรใหญ่

สถานะ: ต้นแบบ v0.1 ยังไม่มีตารางอันดับหรือเซิร์ฟเวอร์ สถิติสูงสุดเก็บในเครื่องผู้เล่น (localStorage)

ทุกเกมเป็นไฟล์ HTML5 ไฟล์เดียว วาดภาพด้วยโค้ดล้วน ไม่มีรูปภาพหรือไลบรารีเกมภายนอก
