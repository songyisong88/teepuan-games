# AUDIO_LICENCE — สถานะสิทธิ์เชิงพาณิชย์ของเสียงพากย์ (edge-tts)

ตรวจเมื่อ 28 ต.ค. 2026 จากหน้าเว็บสาธารณะ (ลิงก์ท้ายเอกสาร) · **ผู้เขียนไม่ใช่ทนายความ และเอกสารนี้ไม่ใช่คำปรึกษาทางกฎหมาย** — ก่อนเก็บเงินหรือแจกจ่ายแอปจริง ต้องให้ทนายหรือฝ่ายกฎหมายยืนยัน

## 1. เสียงในแอปตอนนี้
- `audio/` มี 5,331 คลิป mp3 (~80 MB) สร้างด้วย **edge-tts** (ไลบรารี Python ไม่เป็นทางการ) ผ่านสคริปต์ `gen.py` ใช้เสียง `zh-CN-XiaoxiaoNeural` (หญิง) และ `zh-CN-YunxiNeural` (ชาย) พร้อมปรับ rate ตามบริบท · แมปข้อความ→ไฟล์อยู่ใน `audio-index.js`
- ข้อความทั้งหมดเป็นประโยค/คำที่เขียนเองในแอป (เจ้าของข้อความคือเรา ไม่มีปัญหาเรื่องสิทธิ์ของ “ข้อความต้นทาง”)
- ปริมาณทั้งหมด: 35,604 ตัวอักษร (เป็นอักษรจีน 31,035) — ตามวิธีนับของ Azure (อักษรจีนนับเป็น 2) ≈ **66,639 ตัวอักษรที่คิดเงิน** สำหรับสร้างทั้งชุดใหม่หนึ่งรอบ

ปัจจุบันเดโมบน GitHub Pages มีเสียงเหล่านี้เปิดสาธารณะอยู่แล้ว — ควรปิด/ย้ายถ้าความเสี่ยงนี้รับไม่ได้ก่อนแจกลิงก์วงกว้าง

## 4. คำแนะนำ (ให้เจ้าของโปรเจกต์ตัดสิน)
1. **ก่อนเปิดขายจริง**: เปลี่ยนไปทางเลือก A (ถูกและเร็ว: ไม่ถึง 2 ดอลลาร์ + ฟังตรวจ) หรือ B (ถ้ามีงบ ได้เจ้าของภาษาตรวจด้วย)
2. **ระหว่างนี้ (เดโมสาธารณะ)**: หน้า terms ที่ `build.js` สร้างระบุอยู่แล้วว่า “เสียงอ่านเป็นเสียงสังเคราะห์ ยังไม่ได้ให้เจ้าของภาษาตรวจ” (ยังไม่ได้พูดถึงที่มาของเสียงหรือสถานะสิทธิ์ — ควรเพิ่มเมื่อตัดสินใจแล้ว) · ถ้าต้องถอดเสียง: โค้ด `core.js` (`playOne`) ถอยไปใช้เสียงอ่านของเบราว์เซอร์เมื่อไม่มีไฟล์/เล่นไม่ได้ (ตรวจจากโค้ด ยังไม่ได้ทดสอบจริงหลังลบ `audio/`)
3. **อย่าส่งคำถามถึง Microsoft แทนเจ้าของ** — ถ้าต้องการหลักฐานลายลักษณ์อักษร ให้เจ้าของ/ทนายส่งเอง
4. เก็บบันทึกว่า “คลิปชุดนี้สร้างเมื่อ 2026 ด้วย edge-tts” ไว้เพื่อใช้ลบ/แทนที่ทีหลัง (แมป `audio-index.js` ไม่ต้องเปลี่ยนถ้าแทนที่ไฟล์ชื่อเดิม)
