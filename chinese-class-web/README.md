# ลามะ ภาษาจีน — เว็บเรียนจีนแบบมีสังคมใน LINE (ตัวอย่างทดลอง v2)

เว็บ static (HTML/CSS/vanilla JS) เปิดดูได้ที่ GitHub Pages — **ยังไม่ใช่ระบบจริง** ไม่มี backend ไม่มีบัญชีผู้ใช้จริง ไม่มีการชำระเงิน และไม่ได้เชื่อมกับ LINE จริง ข้อมูลผู้เรียนเก็บใน `localStorage` ของเบราว์เซอร์เท่านั้น (key `lama-cn-web-demo-v2`)

ชื่อแอปและชื่อตัวละครเป็นชื่อ **ชั่วคราว** แก้ที่ `config.js` (`BRAND_NAME`, `MASCOT_NAME`) — ข้อความใน `index.html` (meta) และ `manifest.webmanifest` ต้องแก้ตามเอง

## มาตรฐานเนื้อหา (อ่านก่อน)
**มาตรฐาน HSK 2.0 (ปี 2012)** — ระดับของบทจัดตามรายการคำ HSK 2.0 รายคำ (ที่มา: complete-hsk-vocabulary/drkameleon ชุด “old”, ยังไม่ได้เทียบ PDF ทางการ) แต่บทเรียน ประโยค บทสนทนา และข้อสอบทุกอย่าง **เขียนขึ้นเองในแอป ไม่ใช่ข้อสอบจริง** และ **ยังครอบคลุมคำทางการไม่ครบ** (HSK1 149/150 · HSK2 107/147 · HSK3 216/298 · HSK4 295/598 · HSK5 453/1,298) · ตัวชี้วัด in-level % รายบท/รายระดับดู `ROADMAP.md` หัวข้อ 4 · ยังไม่ได้ให้เจ้าของภาษาตรวจ (รายการตรวจ: `REVIEW_CHECKLIST.md`) · คำว่า “HSK” ใช้เป็นป้ายระดับภายในแอปเท่านั้น ไม่อยู่ในชื่อแบรนด์/ชื่อหน้า/manifest/ข้อความ OA · แผนย้ายไป HSK 3.0 ดู `ROADMAP.md`

## จุดต่างจากแอปเรียนภาษาทั่วไป
- เนื้อหา 5 ระดับ (ป้ายระดับ HSK1–5 ภายในแอป) รวม 211 บท 3,376 คำ ไม่ซ้ำ (บท/คำ: HSK1 12/192 · HSK2 9/144 · HSK3 21/336 · HSK4 40/640 · HSK5 129/2,064) เรียนผ่านประโยคและบทสนทนาสั้น 16 คำ/บท เสียงพากย์ + พินอิน + ตัวช่วยจำภาษาไทย · เลือกระดับเองหรือทดสอบวัดระดับ (ปรับระดับ 70 ข้อ) · ทวนด้วยระบบเว้นช่วง (Leitner SRS)
- ท่องจำผ่านคำช่วยจำภาษาไทย, ฝึกวรรณยุกต์ (ตัวเทียบเสียงไทยโดยประมาณ), เกมสั้น 5 เกม, ห้องเรียนสะสมเพื่อนร่วมห้อง
- ดึงจุดแข็งของ LINE: ชวนเพื่อนเรียน (บัดดี้สตรีค), ท้าเพื่อน, การ์ดแชร์ผลลัพธ์, แข่งห้องต่อห้อง, กลุ่มเรียน, LINE OA เตือนสตรีค
- **ห้องฝึกพิเศษ 5 แบบ (Package B · หน้า Home → “ห้องฝึกพิเศษ”)**: ซีรีส์ลามา (นิทานสั้น 49 เรื่อง + ควิซท้ายเรื่อง), เทียบคำใกล้เคียง (68 คู่), ชาโดว์อิ้ง (ฟัง → พูดตาม → ประเมินตัวเอง), ข้อสอบจำลองย่อย (คลัง 20 ข้อ/ระดับ สุ่ม 10 ข้อต่อรอบ เขียนเอง), การ์ดส่วนประกอบตัวอักษร (ตัวช่วยจำภาษาไทย) — ผลลัพธ์ของห้องฝึกแชร์เป็นการ์ดภาพไป LINE ได้ (จำลอง: เลือกเพื่อนในแอปเดโม; ของจริงต้องใช้ LINE LIFF shareTargetPicker) — ดูสถานะจริง/จำลองในตารางด้านล่าง
- ไม่น่าเบื่อ: อีเวนต์รายวัน, ตั๋วกันสตรีค, ของขวัญตอนกลับมา, ภารกิจ, กล่องสุ่ม, แผนที่เส้นทางเรียน, สรุปรายสัปดาห์
- ลีกรายสัปดาห์ (เลื่อน/ตกชั้น), เหรียญตรา 34 ใบ + ฉายา, ธีมประจำสัปดาห์ + สมุดแสตมป์ 7 วัน + ภารกิจสัปดาห์, เกมทีมชนทีม/วิ่งผลัด, การ์ดแชร์ 3 สไตล์

## จริง vs จำลอง
| ส่วน | สถานะ |
|---|---|
| บทเรียน เนื้อหา เสียง (edge-tts 9,036 คลิปใน `audio/`) การให้คะแนน สตรีค XP เหรียญ SRS ระดับ เหรียญตรา ธีมสัปดาห์ | ทำงานจริงในเบราว์เซอร์ เก็บใน localStorage ของเครื่อง |
| การ์ดแชร์ (canvas → PNG) + Web Share API | ทำงานจริงบนเบราว์เซอร์ที่รองรับ (มือถือ) |
| รายชื่อเพื่อน อันดับ ลีก ห้อง/กลุ่ม แชทกลุ่ม ทีมชนทีม/วิ่งผลัด ห้องต่อห้อง บัดดี้ | **จำลอง** (เพื่อนและคู่แข่งเป็นบอทสุ่ม ไม่ใช่ผู้เล่นจริง) |
| ติวเตอร์ AI | **จำลอง** (กฎที่เขียนไว้: แก้ประโยค ~44 แพตเทิร์น, ไวยากรณ์ ~66 หัวข้อ, เคล็ดลับออกเสียง, ขอประโยคตัวอย่าง) ต่อ AI จริงได้ที่ `TUTOR_ADAPTER` |
| `line.html` (แชท LINE OA + Rich menu + โควตา push) | **จำลอง** เพื่อแสดงแนวคิด |
| `line.html` → Rich menu หน้า “คลาส” (คลาสวันนี้ 3 คำ / ควิซ 3 ข้อ แบบดึง) และแท็บ “อ่านด้วยกัน” (ห้องจับเวลา 25 นาที เพื่อนเป็นตัวจำลองป้ายกำกับชัดเจน) | **จำลองทั้งหมด** — ไม่ได้เชื่อม LINE จริง; ของจริงต้องมีเซิร์ฟเวอร์ webhook รับ postback แล้วตอบด้วย reply API (ฟรี ไม่นับโควต้า) และเซิร์ฟเวอร์ซิงก์เวลา/สถานะห้อง ซึ่งยังไม่มี |
| ห้องฝึกพิเศษ: ซีรีส์ลามา, เทียบคำ, การ์ดส่วนประกอบ, ข้อสอบจำลองย่อย | ทำงานจริงในเบราว์เซอร์ (คิดคะแนนเอง เก็บใน localStorage) · **เนื้อหาเขียนเองและยังไม่ผ่านเจ้าของภาษา** · ข้อสอบจำลองไม่ใช่ข้อสอบจริง ค่าประมาณผลเป็นเพียงข้อบ่งชี้ · ตัวช่วยจำส่วนประกอบเป็นเครื่องมือช่วยจำ ไม่ใช่นิรุกติศาสตร์ |
| ชาโดว์อิ้ง | ฟังเสียง edge-tts (หรือเสียงเบราว์เซอร์สำรอง) แล้วผู้เรียน **ประเมินตัวเอง** — **ไม่มีไมค์ ไม่อัดเสียง ไม่อัปโหลด ไม่มีคะแนนการออกเสียงอัตโนมัติ** |
| แผน Plus 99฿ / Buddy 159฿ | แสดงราคาเท่านั้น ซื้อไม่ได้ |
| ข้อมูลที่ต้องมีเซิร์ฟเวอร์ (อันดับจริง เพื่อนจริง) | ยังไม่มี |

## ข้อจำกัดของ LINE ที่ต้องรู้ก่อนทำของจริง
- ไม่มี API ดึงรายชื่อเพื่อนของผู้ใช้ — "เลือกเพื่อน" ต้องใช้ LIFF `shareTargetPicker` (ผู้ใช้เลือกเองในหน้าต่างของ LINE)
- Push/broadcast จาก LINE OA จำกัดและนับตามผู้รับ: แผนฟรีของไทย 300 ข้อความ/เดือน, Basic 1,280฿ = 15,000 ข้อความ, Pro 1,780฿ = 35,000 ข้อความ (ตรวจแล้ว ตุลาคม 2026 — ราคาอาจเปลี่ยน) ส่วน **reply message ฟรีและไม่นับ** ดังนั้นออกแบบให้ผู้ใช้เป็นฝ่ายทักก่อน (Rich menu) และใช้ push เฉพาะที่จำเป็นจริง ๆ
- ทางแชร์ที่ใช้ได้จริง: LIFF `shareTargetPicker` + Flex Message; ในเดโมนี้ใช้ Web Share API แทน

## ข้อควรระวัง / ช่องว่างที่ทราบ
- ตรวจข้อมูลอัตโนมัติ: `node tools/dump.cjs && python3 tools/validate.py` (ต้องมี pypinyin + opencc-python-reimplemented; เทียบกับ `tools/hsk20-words.json` ในตัว, `--lessons` แสดง in-level % รายบท) — รอบล่าสุด 211 บท ERROR 0, WARN 115 · **ยังไม่มีเจ้าของภาษาตรวจ**
- ระดับ HSK1–5 จัดตามรายการ HSK 2.0 แล้ว (in-level % headline 86–91% ต่อระดับ, strict 69–75%) · 211 บท (HSK1 12 · HSK2 9 · HSK3 21 · HSK4 40 · HSK5 129) ครอบคลุมรายการ HSK 2.0 ครบทุกระดับ (150/147/298/598/1,298 คำ) · ห้องฝึกพิเศษ: ซีรีส์ลามา 49 ตอน, เทียบคำ 90 คู่, ข้อสอบจำลอง 150 ข้อ (30/ระดับ, สุ่ม 10 ข้อ/รอบ), การ์ดส่วนประกอบ (ตัวเลขจริงดู `ROADMAP.md` หัวข้อ 4)
- เสียงพากย์สร้างด้วย edge-tts: ตรวจเงื่อนไขการใช้งานเชิงพาณิชย์ก่อนปล่อยจริง (สรุปผลตรวจ+ทางเลือก: `AUDIO_LICENCE.md` — ยังไม่ยืนยันว่าใช้เชิงพาณิชย์ได้) หรือเปลี่ยนเป็นเสียงอัดจริง/บริการที่มีสัญญา
- เสียงของตัวอักษรเดี่ยวอาจออกเสียงเพี้ยนบางตัว (ควรให้เจ้าของภาษาตรวจ)
- ตัวเทียบเสียงไทยในหน้าวรรณยุกต์เป็นการประมาณ ไม่ตรงทั้งหมด
- รูปเพื่อนร่วมห้อง s02, s08 ถูกตัดออกจากชุด (กันความคล้ายตัวละครที่มีลิขสิทธิ์)
- ภาพมาสคอตชุดนี้ห้ามใช้แนวหญ้า/โคลน/ม้า
