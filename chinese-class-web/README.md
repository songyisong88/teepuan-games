# ลามะ ภาษาจีน — เว็บเรียนจีนแบบมีสังคมใน LINE (ตัวอย่างทดลอง v2)

เว็บ static (HTML/CSS/vanilla JS) เปิดดูได้ที่ GitHub Pages — **ยังไม่ใช่ระบบจริง** ไม่มี backend ไม่มีบัญชีผู้ใช้จริง ไม่มีการชำระเงิน และไม่ได้เชื่อมกับ LINE จริง ข้อมูลผู้เรียนเก็บใน `localStorage` ของเบราว์เซอร์เท่านั้น (key `lama-cn-web-demo-v2`)

ชื่อแอปและชื่อตัวละครเป็นชื่อ **ชั่วคราว** แก้ที่ `config.js` (`BRAND_NAME`, `MASCOT_NAME`) — ข้อความใน `index.html` (meta) และ `manifest.webmanifest` ต้องแก้ตามเอง

## มาตรฐานเนื้อหา (อ่านก่อน)
**เนื้อหาอ้างอิงแนว HSK 2.0 เขียนขึ้นเอง ไม่ใช่รายการคำ/ข้อสอบทางการ** — ไม่ได้คัดลอกรายการคำหรือข้อสอบทางการของ HSK คำที่อาจอยู่นอกระดับทางการยังต้องตรวจเทียบ และยังไม่ได้ให้เจ้าของภาษาตรวจ · คำว่า “HSK” ใช้เป็นป้ายระดับภายในแอปเท่านั้น ไม่อยู่ในชื่อแบรนด์/ชื่อหน้า/manifest/ข้อความ OA · แผนมาตรฐานและการย้ายไป HSK 3.0 ดู `ROADMAP.md`

## จุดต่างจากแอปเรียนภาษาทั่วไป
- เนื้อหา 5 ระดับ (ป้ายระดับ HSK1–5 ภายในแอป) เรียนผ่านประโยคและบทสนทนาสั้น 16 คำ/บท เสียงพากย์ + พินอิน + ตัวช่วยจำภาษาไทย · เลือกระดับเองหรือทดสอบวัดระดับ (ปรับระดับ 70 ข้อ) · ทวนด้วยระบบเว้นช่วง (Leitner SRS)
- ท่องจำผ่านคำช่วยจำภาษาไทย, ฝึกวรรณยุกต์ (ตัวเทียบเสียงไทยโดยประมาณ), เกมสั้น 5 เกม, ห้องเรียนสะสมเพื่อนร่วมห้อง
- ดึงจุดแข็งของ LINE: ชวนเพื่อนเรียน (บัดดี้สตรีค), ท้าเพื่อน, การ์ดแชร์ผลลัพธ์, แข่งห้องต่อห้อง, กลุ่มเรียน, LINE OA เตือนสตรีค
- ไม่น่าเบื่อ: อีเวนต์รายวัน, ตั๋วกันสตรีค, ของขวัญตอนกลับมา, ภารกิจ, กล่องสุ่ม, แผนที่เส้นทางเรียน, สรุปรายสัปดาห์
- ลีกรายสัปดาห์ (เลื่อน/ตกชั้น), เหรียญตรา 34 ใบ + ฉายา, ธีมประจำสัปดาห์ + สมุดแสตมป์ 7 วัน + ภารกิจสัปดาห์, เกมทีมชนทีม/วิ่งผลัด, การ์ดแชร์ 3 สไตล์

## จริง vs จำลอง
| ส่วน | สถานะ |
|---|---|
| บทเรียน เนื้อหา เสียง (edge-tts ~2,670 ไฟล์ใน `audio/`) การให้คะแนน สตรีค XP เหรียญ SRS ระดับ เหรียญตรา ธีมสัปดาห์ | ทำงานจริงในเบราว์เซอร์ เก็บใน localStorage ของเครื่อง |
| การ์ดแชร์ (canvas → PNG) + Web Share API | ทำงานจริงบนเบราว์เซอร์ที่รองรับ (มือถือ) |
| รายชื่อเพื่อน อันดับ ลีก ห้อง/กลุ่ม แชทกลุ่ม ทีมชนทีม/วิ่งผลัด ห้องต่อห้อง บัดดี้ | **จำลอง** (เพื่อนและคู่แข่งเป็นบอทสุ่ม ไม่ใช่ผู้เล่นจริง) |
| ติวเตอร์ AI | **จำลอง** (กฎที่เขียนไว้: แก้ประโยค ~44 แพตเทิร์น, ไวยากรณ์ ~66 หัวข้อ, เคล็ดลับออกเสียง, ขอประโยคตัวอย่าง) ต่อ AI จริงได้ที่ `TUTOR_ADAPTER` |
| `line.html` (แชท LINE OA + Rich menu + โควตา push) | **จำลอง** เพื่อแสดงแนวคิด |
| แผน Plus 99฿ / Buddy 159฿ | แสดงราคาเท่านั้น ซื้อไม่ได้ |
| ข้อมูลที่ต้องมีเซิร์ฟเวอร์ (อันดับจริง เพื่อนจริง) | ยังไม่มี |

## ข้อจำกัดของ LINE ที่ต้องรู้ก่อนทำของจริง
- ไม่มี API ดึงรายชื่อเพื่อนของผู้ใช้ — "เลือกเพื่อน" ต้องใช้ LIFF `shareTargetPicker` (ผู้ใช้เลือกเองในหน้าต่างของ LINE)
- Push/broadcast จาก LINE OA จำกัดและนับตามผู้รับ: แผนฟรีของไทย 300 ข้อความ/เดือน, Basic 1,280฿ = 15,000 ข้อความ, Pro 1,780฿ = 35,000 ข้อความ (ตรวจแล้ว ตุลาคม 2026 — ราคาอาจเปลี่ยน) ส่วน **reply message ฟรีและไม่นับ** ดังนั้นออกแบบให้ผู้ใช้เป็นฝ่ายทักก่อน (Rich menu) และใช้ push เฉพาะที่จำเป็นจริง ๆ
- ทางแชร์ที่ใช้ได้จริง: LIFF `shareTargetPicker` + Flex Message; ในเดโมนี้ใช้ Web Share API แทน

## ข้อควรระวัง / ช่องว่างที่ทราบ
- เสียงพากย์สร้างด้วย edge-tts: ตรวจเงื่อนไขการใช้งานเชิงพาณิชย์ก่อนปล่อยจริง หรือเปลี่ยนเป็นเสียงอัดจริง/บริการที่มีสัญญา
- เสียงของตัวอักษรเดี่ยวอาจออกเสียงเพี้ยนบางตัว (ควรให้เจ้าของภาษาตรวจ)
- ตัวเทียบเสียงไทยในหน้าวรรณยุกต์เป็นการประมาณ ไม่ตรงทั้งหมด
- รูปเพื่อนร่วมห้อง s02, s08 ถูกตัดออกจากชุด (กันความคล้ายตัวละครที่มีลิขสิทธิ์)
- ภาพมาสคอตชุดนี้ห้ามใช้แนวหญ้า/โคลน/ม้า
