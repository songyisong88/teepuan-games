## 0. วิธีใช้ (ผู้ตรวจ 1 คน)
1. เปิดแอป → เลือกระดับ (ข้ามการทดสอบได้) → ปุ่มเดโมใน ฉัน → เครื่องมือทดลอง → “จบทุกบท” เพื่อเปิดบทที่ล็อก
2. ตรวจทีละบท (ไฟล์ข้อมูล: `data/hsk1.js … hsk5.js` · รายการบทต่อระดับดูหัวข้อ 3) ตามตารางหัวข้อ 1 → ทำเครื่องหมาย ✅ / ✏️ แก้ / ❌ ตัดทิ้ง ในสเปรดชีตที่ผู้ตรวจสร้างเอง (ใช้ id บทเป็นแถว)
3. เสียง: ไฟล์อยู่ใน `audio/` ชื่อ = sha1 8 ตัวแรกของข้อความ (ตาราง `audio-index.js` map ข้อความ → ไฟล์) — ฟังเฉพาะที่มีใน “รายการเสี่ยง” ก่อนแล้วสุ่ม 10% ของที่เหลือ
4. รายงานกลับเป็นรายการ “id บท · ข้อความเดิม → ข้อความที่ถูกต้อง · เหตุผล” เพื่อให้แก้ใน data/ แล้วสร้างเสียงใหม่ (`/workspace/cn2/gen.py` — ดู ROADMAP หัวข้อ 3)
