# data/rad — ข้อมูลเส้นทาง "อักษรข้าง" (ตัวข้าง / ราก)

`rad.js` สร้างโดย `tools/rad-build/build_rad.py` (รันซ้ำได้) จาก:

| แหล่ง | ใช้ทำอะไร | สัญญา |
|---|---|---|
| **Make Me a Hanzi** (Shaunak Kishore) — `dictionary.txt` (การแยกส่วนประกอบ, ชนิดตัวอักษร, ส่วนเสียง) และ `graphics.txt` (การจับคู่ขีดกับส่วนประกอบ) | แยกตัวอักษรเป็นตัวข้าง/ส่วนเสียง และจับคู่ขีดเพื่อลงสี | Arphic Public License (กราฟิก) + **LGPL-3** (ซอฟต์แวร์/ข้อมูล) — ดู `MMAH-COPYING.txt` |
| Unihan, CJKlib (ผ่าน dictionary.txt ของ MMAH) | พินอิน/นิยาม | ดู `MMAH-COPYING.txt` |
| ชั้นแก้ไขของเรา `tools/rad-build/fixes.json` | แก้การแยกที่ผิดหรือแยกลึกเกินไป ระบุส่วนเสียงที่ใช้ไม่ได้ | ของเราเอง |
| ตารางตัวข้างของเรา `table_core.md` (48 ตัว) `table_bonus.md` (12 ตัว) | ชื่อไทย ตัวช่วยจำ ลำดับบนเส้นทาง | ของเราเอง — **ร่าง รอครูตรวจ** |

## ข้อควรรู้
* ข้อความภาษาไทยทุกชิ้น (ชื่อตัวข้าง ตัวช่วยจำ ชื่อการ์ด ชื่อชุด) เป็น **ร่าง รอครูตรวจ**
* ความน่าเชื่อถือของ "ส่วนเสียง" ที่แอปแสดง คำนวณจากข้อมูลจริงของตัวอักษรในบทเรียน
  (ตรงทั้งพินอินและวรรณยุกต์ / ตรงพยางค์เท่านั้น / ไม่ตรง) ไม่ใช่ตัวเลขจากเอกสารข้อเสนอ
* ไฟล์ `rad.js` เป็นงานดัดแปลงจากข้อมูล MMAH จึงอยู่ภายใต้ LGPL-3 เช่นเดียวกัน
  เมื่อแจกจ่ายต่อ ให้คงไฟล์นี้ `MMAH-COPYING.txt` และเครดิตไว้ด้วย

- ข้อความสัญญา LGPL-3.0 ฉบับเต็ม (ที่ MMAH-COPYING.txt เรียกว่า "the file LGPL") อยู่ที่ `LGPL-3.0.txt` และ GPL-3.0 (ที่ LGPL อ้างถึง) ที่ `GPL-3.0.txt` ในโฟลเดอร์นี้และ `/LICENSES/`
