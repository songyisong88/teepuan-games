นโยบายความเป็นส่วนตัว (ร่างตัวอย่าง)

ร่างตัวอย่าง ยังไม่ผ่านการตรวจโดยผู้เชี่ยวชาญกฎหมาย — ใช้เพื่อบอกสิ่งที่ระบบตัวอย่างนี้ทำจริงในตอนนี้เท่านั้น ไม่ใช่เอกสารทางกฎหมายที่มีผลผูกพัน

ชื่อและข้อมูลผู้ให้บริการจะระบุให้ครบก่อนเปิดใช้งานจริง

ตอนนี้เก็บข้อมูลอะไรบ้าง

เว็บนี้เป็นตัวอย่างทดลอง หากคุณใช้งานโดยไม่เข้าสู่ระบบ ข้อมูลทั้งหมดอยู่ใน localStorage ของเบราว์เซอร์บนอุปกรณ์ของคุณเท่านั้น และไม่ถูกส่งไปยังเซิร์ฟเวอร์ใด ได้แก่:

  • ความคืบหน้าการเรียน คะแนน XP เหรียญ สตรีค ระดับที่เลือก และผลทดสอบวัดระดับ
  • คำที่ตอบผิด การตั้งค่า (เช่น เป้าหมายรายวัน เวลาเตือนแบบจำลอง) ของที่ปลดล็อก
  • จำนวนครั้งที่ใช้ “ติวเตอร์จำลอง” (ข้อความที่พิมพ์ไม่ได้ถูกบันทึกไว้ และประมวลผลในเครื่อง ไม่ได้ส่งไปที่ใด) · หน้าจำลอง LINE เก็บสถานะเปิด/ปิดเตือน ตัวนับข้อความจำลอง และค่าที่ตั้งในแผน ไว้ในเครื่องเช่นกัน

นอกจาก localStorage แล้ว แอปใช้ Service Worker และ Cache Storage ของเบราว์เซอร์เพื่อให้ใช้งานออฟไลน์ได้: เก็บตัวแอป (หน้าเว็บ สคริปต์ ฟอนต์ไทย รูปน้องลามา) ไว้อัตโนมัติหลังเปิดครั้งแรก, เก็บเสียง รูปคำศัพท์ ไฟล์ลำดับขีด และฟอนต์จีนที่เคยเปิด (เสียงเก็บล่าสุด 400 ไฟล์) และเก็บแพ็กที่คุณกดดาวน์โหลดเองในหน้า “ใช้งานออฟไลน์” (ชื่อแคชขึ้นต้นด้วย lama-) — ทั้งหมดเป็นไฟล์สาธารณะของแอปที่ดาวน์โหลดจากเว็บนี้ ไม่มีข้อมูลส่วนตัว ไม่ส่งอะไรออกจากเครื่อง ลบได้จากหน้า “ใช้งานออฟไลน์” ส่วนข้อมูลการฝึกเขียนและความคืบหน้า “อักษรข้าง” (ตัวข้างที่ผ่าน การ์ดที่ได้ ผลเกม) เก็บใน localStorage ด้วยกัน ปุ่ม “ล้างข้อมูลทั้งหมด” จะลบทั้ง localStorage แคชนี้ และยกเลิกการลงทะเบียน Service Worker

สำรองความก้าวหน้า

หน้า “สำรองความก้าวหน้า / ย้ายเครื่อง” สร้างไฟล์ .json หรือรหัสข้อความ ในเครื่องของคุณ ไม่ได้ส่งไปเซิร์ฟเวอร์ใด คุณเป็นผู้เลือกว่าจะเก็บไว้หรือส่งต่อที่ไหน ใครที่ได้ไฟล์/รหัสจะเห็นความก้าวหน้าของคุณ จึงควรเก็บเป็นส่วนตัว

การเข้าสู่ระบบด้วย LINE (ไม่บังคับ)

การเข้าสู่ระบบด้วย LINE เป็นทางเลือก ผู้ที่ไม่เข้าสู่ระบบใช้งานได้ตามปกติและไม่ได้รับผลกระทบใด ๆ หากคุณเลือกเข้าสู่ระบบและให้ความยินยอม เราจะเก็บข้อมูลต่อไปนี้บนเซิร์ฟเวอร์คลาวด์ของ Supabase (ภูมิภาคสิงคโปร์)

  • รหัสผู้ใช้ LINE (userId) ที่ได้รับการยืนยันจาก LINE
  • ข้อมูลความคืบหน้าการเรียน ชุดเดียวกับที่เก็บในเครื่องตามรายการข้างต้น และเวลาที่บันทึกล่าสุด

วัตถุประสงค์: เพื่อเก็บและซิงก์ความคืบหน้าระหว่างอุปกรณ์ของคุณเท่านั้น ไม่ใช้เพื่อการโฆษณา และไม่เปิดเผยแก่บุคคลอื่น นอกจากผู้ให้บริการที่จำเป็น (LINE สำหรับการยืนยันตัวตน และ Supabase สำหรับการจัดเก็บ) · เราไม่เก็บอีเมล เบอร์โทร รายชื่อเพื่อน หรือข้อความแชต ชื่อที่แสดงใน LINE ใช้แสดงในเครื่องเท่านั้น

ระยะเวลาเก็บ: จนกว่าคุณจะลบ หรือเมื่อยุติบริการ · การลบ: หน้า “ฉัน” → “บัญชี LINE” → “ลบข้อมูลบนคลาวด์” จะลบรหัสผู้ใช้ LINE และความคืบหน้าของคุณออกจากเซิร์ฟเวอร์ทันที (ข้อมูลในเครื่องไม่ถูกลบ) · “ออกจากระบบ” จะหยุดซิงก์ แต่ข้อมูลบนคลาวด์ยังอยู่ · หากเข้าสู่ระบบไม่ได้ สามารถขอให้ลบผ่านช่องทางติดต่อด้านบน

สิ่งที่ไม่ได้เก็บ / ไม่ได้ทำ

  • ไม่มีการสมัครสมาชิกด้วยอีเมลหรือรหัสผ่าน ไม่เก็บชื่อ อีเมล เบอร์โทร ที่อยู่ หรือข้อมูลบัตร (ยกเว้นรหัสผู้ใช้ LINE หากคุณเลือกเข้าสู่ระบบ)
  • ไม่มีระบบชำระเงินจริง (ราคาในแอปเป็นตัวอย่าง)
  • ไม่มี analytics หรือเครื่องมือติดตามของบุคคลที่สาม ไม่ใช้คุกกี้โฆษณา
  • ข้อความ “จากเพื่อน/ลีก/การแจ้งเตือน” ที่เห็นเป็นข้อมูลจำลอง ไม่ได้ส่งผ่าน LINE OA จริง

บริการภายนอกที่เกี่ยวข้อง

  • ฟอนต์ (IBM Plex Sans Thai, Inter, Noto Serif SC — สัญญาอนุญาต SIL OFL) โฮสต์ในเว็บไซต์เดียวกัน ไม่โหลดจาก Google อีกต่อไป
  • โฮสต์ด้วย GitHub Pages — GitHub อาจเก็บบันทึกการเข้าถึงตามนโยบายของ GitHub
  • ปุ่มแชร์/เพิ่มเพื่อนจะเปิด LINE หรือแอปแชร์ของอุปกรณ์เมื่อคุณกดเอง
  • LINE Login (LY Corporation) และ Supabase — ใช้เฉพาะเมื่อคุณเลือกเข้าสู่ระบบด้วย LINE ตามหัวข้อด้านบน

สิทธิ์และการลบข้อมูล

คุณลบข้อมูลทั้งหมดได้ทุกเมื่อที่ หน้า “ฉัน” → “ล้างข้อมูลทั้งหมด” หรือล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ สำหรับผู้ที่ไม่ได้เข้าสู่ระบบ ข้อมูลอยู่ในเครื่องคุณ ผู้ให้บริการจึงไม่สามารถเข้าถึงหรือกู้คืนให้ได้ · หากเข้าสู่ระบบด้วย LINE ลบข้อมูลบนคลาวด์ได้ตามหัวข้อ “การเข้าสู่ระบบด้วย LINE”

การเปลี่ยนแปลงในอนาคต

หากมีการเก็บข้อมูลส่วนบุคคลเพิ่มเติม เช่น อีเมล หรือการชำระเงิน เราจะอัปเดตเอกสารนี้ แจ้งวัตถุประสงค์และระยะเวลาเก็บ และขอความยินยอมก่อนเก็บ โดยคำนึงถึงหลักการของ พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล (PDPA) — ข้อความฉบับนี้ยังไม่ใช่การรับรองว่าปฏิบัติตามกฎหมายครบถ้วน

เด็กและเยาวชน

หากผู้ใช้อายุต่ำกว่าเกณฑ์ที่กฎหมายกำหนด ควรให้ผู้ปกครองรับทราบก่อนใช้งานบริการที่มีบัญชีหรือการชำระเงินในอนาคต
