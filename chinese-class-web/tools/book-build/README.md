# ตัวสร้างข้อมูลห้องเรียนคู่หนังสือ

สร้างไฟล์ข้อมูลของหน้า "ห้องเรียนคู่หนังสือ" จากต้นฉบับหนังสือ แล้วสร้างเสียงที่ยังขาด

## คำสั่งรันซ้ำ (จากโฟลเดอร์ chinese-class-web)

```
python3 tools/book-build/build_book.py && node build.js
```

- `--no-audio` สร้างเฉพาะไฟล์ข้อมูล ไม่สร้างเสียง
- `BOOK_DIR=/path/to/beginner-book` เปลี่ยนโฟลเดอร์หนังสือ (ค่าเริ่มต้น /workspace/books/beginner-book)
- ต้องมี `edge-tts`, `ffmpeg`, `ffprobe`, `pdfinfo`, `pdftotext` (poppler-utils) และอินเทอร์เน็ตสำหรับ TTS

## แหล่งข้อมูล

| ข้อมูล | ไฟล์ต้นทาง |
|---|---|
| ภาค บท คำศัพท์ นิทาน แบบทดสอบย่อย | `TOC-final.md` |
| รายการแทร็ก (ทางการ) | `full/audio-tracks.json` (คอลัมน์ track, part, chapter, section, page, exercise, kind, text, items, note) |
| เลขหน้าจริงของเล่ม (B5 ต่อเนื่องทั้งเล่ม) | `full/partN/partN.pdf` (อ่านหัวกระดาษและเลขหน้าจาก PDF) |

เลขหน้าใน TOC-final เป็นแผนเดิม (A4) ไม่ตรงกับเล่มจริง แอปจึงไม่ใช้เลย
ช่วงหน้าของบทมาจาก PDF ของภาคนั้น ถ้ายังไม่มี PDF ใช้หน้าต่ำสุดถึงสูงสุดของแทร็กในบท
ถ้าไม่มีทั้งสองอย่าง แอปจะไม่แสดงเลขหน้า

## ผลลัพธ์ (ห้ามแก้มือ)

- `data/book1.js` โครงหนังสือ (`window.BOOK1`)
- `data/book1-tracks.js` แทร็กทั้งหมด พร้อมไฟล์เสียงและความยาว (`window.BOOK1_TRACKS`)
- `data/book1-audio.js` เสียงคำและประโยคที่เพิ่มใหม่ (`window.BOOK1_AUDIO`)
- `audio/<hash>.mp3` ไฟล์เสียง

## การรันซ้ำเมื่อเพิ่มภาค 3–5

รันซ้ำได้ทุกเมื่อ ผลเหมือนเดิมถ้าต้นฉบับไม่เปลี่ยน
- ชื่อไฟล์เสียงของแทร็กคำนวณจากรหัสแทร็กและข้อความที่อ่าน แทร็กเดิมจึงได้ไฟล์เดิมและไม่สร้างใหม่
- ระบบสร้างเสียงเฉพาะแทร็กใหม่หรือแทร็กที่ข้อความเปลี่ยน
- คำศัพท์ที่มีเสียงในแอปอยู่แล้ว (audio-index.js) ใช้ของเดิม

เสียงทำด้วย TTS zh-CN-XiaoxiaoNeural ความเร็ว -8% เว้นช่วงระหว่างคำ 0.9 วินาที
แทร็กฟังที่โจทย์ระบุ "อ่าน 2 ครั้ง" จะอ่านแต่ละข้อสองรอบ

หลังรันแล้ว commit เฉพาะ `data/book1*.js`, `audio/*.mp3` ที่เพิ่มใหม่, `sw.js` และ `version.json`
ไม่ต้อง commit `tools/book-build/cache/`
