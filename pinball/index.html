DEEP CORE PINBALL — เจาะลึกลงสู่แกนโลก ทำภารกิจให้ได้คะแนนสูงสุด
• แตะ/กดค้าง ครึ่งซ้าย ของจอ = ไม้ตีซ้าย
• แตะ/กดค้าง ครึ่งขวา ของจอ = ไม้ตีขวา (กดสองข้างพร้อมกันได้)
• ตอนลูกอยู่ในช่องยิง: กดค้างครึ่งขวา ให้แถบพลังขึ้น แล้ว ปล่อย เพื่อยิง
• คีย์บอร์ด: Z / ← = ซ้าย, / / → = ขวา, Space = ยิงลูก, F2 = เกมใหม่, P = พัก
• มี 3 ลูก ช่วงแรกของแต่ละลูกมี BALL SAVE
• ทำภารกิจครบ 3 อย่าง เปิดไฟ EXTRA BALL ที่หลุมกลาง
• ผ่านเลนบนครบ C-O-R-E = เพิ่มตัวคูณโบนัส
